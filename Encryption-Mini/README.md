# Encryption-Mini
Encryption System <br>
This is a toy/project encryption system, not intended for genuine use. <br>
Decryption 1 is vibecoded, everything else is human-made. <br>
<br><br>
List of Encryption Algorithms:<br>
Encryption 1: A very basic algorithm consisting of multiplication then swapping.<br>
Encryption 1+: The same as Encryption 1, but the decryption algorithm is human made and the code has been optimized a bit. Backwards compatible with Encryption 1.<br>
Encryption 2: An upgrade of Encryption 1/1+, with key-based lookup table generation and improved swap. Not backwards-compatible. <br>
